## Content rules

- Do not add invented customers, testimonials, prices, guarantees, delivery dates, certifications, or
  performance results.
- Clearly distinguish current capabilities from possible future work.
- Do not place prompts, agent instructions, secrets, credentials, or private customer information here.
- Prefer short sections with descriptive headings so retrieval can return a focused passage.
- Update content through review and deployment; public agents should not fetch GitHub during a conversation.
